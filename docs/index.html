Quick Start

To run from source, follow the steps in the README. For Windows users, grab the installer from Releases.

  • Backend (Flask): cd backend && python app.py
  • Frontend (React): cd frontend && npm start
  • Desktop (Electron): cd desktop-app && npm run dev
