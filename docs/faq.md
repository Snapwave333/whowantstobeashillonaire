# FAQ

## Why are AI-generated questions not appearing?
- Ensure your Gemini API key is set correctly in the Game Master Settings.
- Verify backend is running and reachable from the desktop app.

## How do I customize the prize ladder?
- Use the Game Master interface to edit prize amounts and safe havens.

## Where are builds?
- Check the GitHub Releases page for `.exe` and `.zip` downloads.

## How do I report bugs or request features?
- Use GitHub Issues with the provided templates.

## How do I contribute?
- See CONTRIBUTING.md and follow Conventional Commits.
